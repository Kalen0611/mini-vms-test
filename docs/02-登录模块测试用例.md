# MiniVMS 登录模块测试用例

## 1. 测试目标

验证MiniVMS登录接口在正确账号、错误账号、不同用户角色及空值输入等情况下，能够返回符合需求的状态码和响应内容。

## 2. 测试范围

- 登录成功场景
- 用户角色识别
- 用户名或密码错误场景
- 用户名或密码为空场景
- 请求字段缺失场景
- 接口返回状态码及提示信息验证

## 3. 测试环境

- 操作系统：macOS
- Python版本：3.14.4
- Web框架：FastAPI
- 测试框架：pytest
- 接口测试工具：FastAPI TestClient
- 测试方式：本地自动化接口测试

## 5. 测试设计方法

### 等价类划分

将登录数据分为有效账号、无效账号、错误密码和空值输入等不同类别，分别选择代表性数据进行测试。

### 边界值分析

针对用户名和密码长度的最小边界进行测试，检查空字符串和缺少字段时接口能否正确处理。

### 场景覆盖

覆盖管理员、操作员和访客三种用户角色，验证不同角色登录后返回的身份信息是否正确。

## 6. 通过标准

- 所有P0级测试用例必须通过。
- 接口状态码与预期结果一致。
- 登录成功时返回正确的用户名和角色。
- 登录失败时不得返回用户密码等敏感信息。
- 异常输入不得导致服务崩溃。
