# BUG-DEVICE-001 设备端口字段缺失

## 1. 缺陷信息

- 缺陷编号：BUG-DEVICE-001
- 缺陷标题：添加设备接口未保存和校验端口字段
- 关联需求：REQ-DEVICE-001、REQ-DEVICE-004、REQ-DEVICE-005
- 所属模块：设备管理
- 严重程度：S2 严重
- 优先级：P1 高
- 当前状态：已关闭
- 发现阶段：功能测试

## 2. 测试环境

- 操作系统：macOS
- Python版本：3.14.4
- Web框架：FastAPI
- 测试环境：本地开发环境
- 测试接口：POST /api/devices

## 3. 前置条件

MiniVMS服务已经启动，并且可以正常访问Swagger接口文档。

## 4. 复现步骤

1. 打开Swagger接口文档。
2. 找到POST /api/devices接口。
3. 输入合法设备名称、IP地址、端口和设备类型。
4. 点击Execute发送请求。
5. 查看接口响应内容。
6. 将端口改为0，再次发送请求。

## 5. 测试数据

```json
{
  "name": "端口测试摄像机",
  "ip_address": "192.168.1.110",
  "port": 8000,
  "device_type": "网络摄像机"
}
```  

非法端口测试数据：

```json
{
  "name": "非法端口摄像机",
  "ip_address": "192.168.1.111",
  "port": 0,
  "device_type": "网络摄像机"
}
```

## 6. 预期结果

- 系统应保存并返回设备端口。
- 合法端口范围应为1至65535。
- 端口为0、负数或大于65535时，应返回422。
- 只有IP地址和端口均相同时，才应判定为重复设备。

## 7. 实际结果

- 修复前，接口未保存和返回端口字段。
- 修复前，端口为0时仍可以添加设备。
- 修复前，系统仅根据IP地址判断重复设备。

## 8. 影响分析

设备信息不完整，无法准确描述设备的网络连接地址；端口校验和重复设备判断不符合需求，影响设备管理模块验收。

## 9. 修复方案

1. 在DeviceCreate模型中增加port字段。
2. 将端口范围限制为1至65535。
3. 在设备响应中保存并返回port。
4. 使用IP地址和端口组合判断重复设备。

## 10. 缺陷处理记录

- 修复版本：v0.1.1
- 修复日期：2026-09-16
- 修复内容：增加端口字段及范围校验，并使用IP地址和端口组合判断重复设备。
- 回归范围：合法端口、端口为0、端口为65536、重复IP和端口、相同IP不同端口。
- 回归结果：全部通过。
- 最终状态：已关闭。
